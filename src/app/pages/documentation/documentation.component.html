Welcome to RoboSwarm!

RoboSwarm's goal is to make running large load & performance tests with Locust easy. If you notice any bugs or have features that you would like to see, don't hesitate to reach out to jack@kernl.us. We'll get back to you as soon as humanely possible.

Creating a Swarm

To create a swarm for your load tests to execute on you'll need to have the following information:

  • How many users will you load test simulate?
  • What will be the duration of your load test?
  • How quickly will your load test ramp up?
  • Where should traffic originate from? RoboSwarm supports 8 different locations around the world.
  • A zipped copy of your load test.

To get started click the "Swarms" menu button, and then click "Create Swarm". Fill out all of the form fields using the information above. The one potential hang up is how to determine the size your Swarm. This greatly depends on the complexity of your test suite, but our advice is somewhere around 300-400 users per machine in your Swarm.

For example, lets say that you were going to run a load test with 30,000 users. We would recommend creating a Swarm of around ~75 machines. (30000 / 400 = 75)

After you've created your Swarm it will take a few minutes for the Swarm to be created. All RoboSwarm test clusters are ephemeral, which means we create a new cluster on new hardware for every test. We do this using Digital Ocean's lovely API.

Once the Swarm has come online the load test will start immediately.
