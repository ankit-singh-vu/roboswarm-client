To create your WooCommerce load test template, we need a few pieces of information.

The name of this template. Example: "RoboSwarm Store Staging"
(Optional) A longer description of this template.
The URL path to a list of products. This is often the home page of your store, but could be /shop or something similar. Example: /shop (NOT: https://example.com/shop)
The URL path to your shopping cart page. Example: /my/cart (NOT: https://example.com/my/cart)
The URL path to your checkout page. Example: /checkout (NOT: https://example.com/checkout)
The URL path to one of your products. Example: /my-great-product (NOT: https://example.com/my-great-product)
