Site Ownership Verification

Before you can start a load test you must first verify that you own the site. This security measure helps prevent abuse. To verify your site you'll need to do one of the following:

  • Add a verification TXT record to the domain.
  • Add a meta tag to the HEAD block of your site.
  • Install the Kernl Site Verification WordPress plugin.

Site Ownership Verification Documentation

RoboSwarm has several different methods for verifying your site ownership. You only need to do one type of verification.

DNS TXT Record Verification

If you have access to your site's DNS records, adding a TXT record might be the easiest option. To do that, go to your DNS control panel, find your domain, and add a text record with the value listed in the site ownership table.

DNS records can take time to propagate. If verification doesn't work right away, try again in 20 minutes. If it still doesn't work, you might need to wait longer. DNS records can take up to 48 hours to propagate across the globe.

HTML Meta Tag Verification

Another method of site verification is to add an HTML Meta tag to your site with your verification code. 

<meta name="kernl-verify" content="your-verification-code-goes-here">

Add this in the <header> of your site and then click the "verify" button. If you have caching enabled you will need to flush the cache before RoboSwarm can see the change.

WordPress Plugin Verification

The final method of verification available to you is to use the Kernl Site Verification plugin. If your wondering "why Kernl?", it's because RoboSwarm is developed by the same team.

Download Now

Once downloaded and installed, go to Settings => General and scroll to bottom. Enter your site verification code in the "Kernl Site Verification" section.

As with the meta tag method above, please make sure to clear all of your WordPress caches before attempting to verify the site again.
