• Headers

    For each header you would like included in this request, create a new line. Headers should formatted in key:value format.

    Example
    Content-type:application/json
Accept-Encoding:gzip,deflate
Cache-Control:no-cache
  • Body

    This is the body that will be sent with POST/PATCH/PUT requests.

    Example Formatting
      form_key_1:my value
  form_key_2:another value
    The content type that the POST/PUT/PATCH should be sent with.
  • Auth Users !

    Upload a CSV of users and passwords below. A user will be pulled from this CSV during load tests. For example, if you run a load test with 50 users and upload a CSV with 50 users, you can count on 50 different users being authenticated concurrently during the test.

    Example
     jack@kernl.us,mypassword
 jane@roboswarm.dev,anotherPassword
 wow@muchdoge.co,password

    RoboSwarm will validate your CSV formatting before continuing the template setup process.

  • Query Parameters

    For each query parameter you would like included in this request, create a new line. Query parameters should formatted in key:value format.

    Example: ?page=2&q=some%20query&limit=2
    page:2
q:some query
limit:2
