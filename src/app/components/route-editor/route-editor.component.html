Tabs for headers, query params, body, etc
  • Headers

    For each header you would like included in this request, create a new line. Headers should formatted in key:value format.

    Example
    Content-type:application/json
Accept-Encoding:gzip,deflate
Cache-Control:no-cache
  • Query Parameters

    For each query parameter you would like included in this request, create a new line. Query parameters should formatted in key:value format.

    Example: ?page=2&q=some%20query&limit=2
    page:2
q:some query
limit:2
